## The problem with looking at neurons

Causal abstraction asks whether a simple interpretable model is a faithful description of
what a network is doing. The test is the interchange intervention: take the part of the
network you think holds variable $V$, swap its value between two inputs, and see whether
the output changes as the high-level model says it should.

The hard part is knowing which part of the network to swap. Earlier work searched over sets
of neurons, which has two problems. The search is combinatorial, and it presumes that a
variable lives in some group of neurons in the first place.

Under superposition, that presumption fails.
[Features are stored as directions that are not axis-aligned](https://transformer-circuits.pub/2022/toy_model/index.html),
and one neuron participates in many features. Searching over neuron groups is searching a
basis the network never agreed to use.

## What DAS does instead

Learn the basis.

DAS optimises a rotation matrix by gradient descent, mapping the activation space into a
new frame. The concept is then looked for along directions in that rotated space. Nothing
requires the result to correspond to any set of neurons, and one neuron can contribute to
several variables at once.

The objective is still the interchange intervention, so the criterion stays causal: a good
alignment is one where swapping the identified representation produces the output change
the high-level model predicts.

On controlled tasks with binary variables — equality, lexical entailment — DAS recovers
exact alignments where the neuron-subset search found nothing.

## Why it belongs on a list about refusal

The methodological pattern here is the one worth taking.

Difference-in-means picks a direction by a formula and then hopes it is the right one.
DAS defines what makes a direction correct — it must support the causal intervention — and
searches for one that satisfies it.
[Concept Cones](https://arxiv.org/abs/2502.17420) applies that same logic to refusal:
define the objective, optimise the direction, and get both a better direction and a more
honest picture of the structure.

The caution comes with it. A learned rotation is a powerful search, and a powerful search
can find structure that is not there. Whenever a paper says gradient descent located a
concept, the question to ask is what was held out.
