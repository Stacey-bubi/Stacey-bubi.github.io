## What superposition is

Give a network more features to represent than it has dimensions and it does not drop the
extra ones. It stores them anyway, as directions that are close to orthogonal but not
exactly orthogonal. Any two features overlap slightly, which produces interference when both
are active at once.

The trade is worth it when features are sparse. If two features almost never fire together,
their interference almost never gets paid. So the network packs in far more features than
dimensions and pays a small expected cost.

A neuron in that arrangement has no single meaning. It sits at the intersection of several
feature directions and fires for all of them. That is polysemanticity — not sloppiness, but
what an efficient compression scheme looks like from outside. Both kinds of neuron coexist
in the same model: some clean and monosemantic, others thoroughly polysemantic, depending on
the sparsity and importance of what they encode.

## Why sparsity gives independence without orthogonality

This is the part I keep reaching for, and it is a different argument from the geometric one.

Take a 4096-dimensional residual stream with roughly 10 features active at a time. The
number of possible sparse activation patterns is combinatorially vast — on the order of
$10^{26}$. Against a space that large, the chance that two given features are active
simultaneously is tiny.

So features behave independently *in practice* even though they are not perpendicular and
there are far more of them than there are dimensions. Independence here comes from
co-occurrence statistics, not from geometry.

That reframes what "millions of features in 4096 dimensions" means. It is not paradoxical,
it is what sparsity buys you.

It is also worth holding next to [Concept Cones](https://arxiv.org/abs/2502.17420), which
shows orthogonality does not imply independence under intervention. Between the two,
orthogonality turns out to be neither necessary nor sufficient for the property people
actually want — a surprisingly weak tool to be resting so much interpretability work on.

Superposition is also one of the causes of
[anisotropy](https://aclanthology.org/D19-1006/), alongside the training-dynamics and
rogue-dimension explanations. They are complementary, not competing.

## What is actually linear here

The linearity claim is more slippery than it first sounds.

The features themselves are wildly non-linear functions of the input — recognising a face
from pixels is not linear. What is linear is only the **storage**: once the network has
computed a feature, it writes it as a direction, and multiple active features are stored as
a weighted sum $\sum_i x_i W_i$.

Non-linear feature, linear storage. Those get conflated constantly.

## The honest weakness

The paper defines a representation as linear if features correspond to directions in
activation space. It then notes, to its credit, that whether something *is* a linear
representation depends on what you decide the features are.

That is a real problem. If no linear direction is found for some concept, one can always
respond that the concept was carved up wrongly and try a different decomposition. The
hypothesis is very hard to falsify.

I do not think that makes it useless — it is clearly a productive frame, and most of this
list depends on it. But it deserves to be described as a useful abstraction rather than an
established fact, and the papers built on top of it tend to state it far more confidently
than this one does.

Worth remembering too that these are toy models on synthetic data. The extrapolation to real
language models is an argument, not a measurement.
