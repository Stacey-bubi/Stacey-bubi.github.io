## The problem with looking at neurons

Causal abstraction asks whether a simple interpretable model is a faithful description of what
a network is doing. The test is the interchange intervention: take the part of the network you
think holds variable $V$, swap its value between two inputs, and see whether the output changes
as the high-level model says it should.

The hard part is knowing which part to swap. Earlier work searched over sets of neurons, which
has two problems. The search is combinatorial, and it presumes a variable lives in some group of
neurons in the first place.

Under superposition, that presumption fails.
[Features are stored as directions that are not axis-aligned](https://transformer-circuits.pub/2022/toy_model/index.html),
and one neuron participates in many features. Searching over neuron groups is searching a basis
the network never agreed to use.

## What DAS does instead

Learn the basis.

DAS optimises a rotation matrix by gradient descent, mapping the activation space into a new
frame, then looks for the concept along directions in that rotated space. Nothing requires the
result to correspond to any set of neurons, and one neuron can contribute to several variables
at once.

The objective is still the interchange intervention, so the criterion stays causal. On
controlled tasks with binary variables — equality, lexical entailment — DAS recovers exact
alignments where the neuron-subset search found nothing.

## Why it belongs on a list about refusal

The methodological pattern here is the one worth taking.

The rotation is the important idea, and it keeps recurring. The neuron basis is arbitrary, and
concepts have no reason to line up with it; if you only look at axis-aligned groups of neurons
you will miss anything stored at an angle, which under superposition is nearly everything.

Difference-in-means picks a direction by a formula and hopes it is the right one. DAS defines
what makes a direction correct — it must support the causal intervention — and searches for one
that satisfies it. [Concept Cones](https://arxiv.org/abs/2502.17420) applies exactly that logic
to refusal, and gets both a better direction and a more honest picture of the structure.

The evaluation standard is also stricter than what most steering papers use. A probe finding a
concept only shows the information is present. An interchange intervention that changes the
output as predicted shows the model is using it.

## The caution that comes with it

A sufficiently expressive learned rotation can find structure that is not really there, because
the search itself is powerful enough to fit something. Any DAS result needs held-out evaluation
to be believable, and that is worth remembering whenever a paper reports that gradient descent
located a concept.

The tasks here are also small and controlled by design. That is what makes the alignments
verifiable, but it means the demonstration is on simple relations, not on anything like refusal.
And the method requires a high-level causal model specified in advance — you have to know what
hypothesis you are testing, so it is a tool for checking a theory, not for discovering one.
